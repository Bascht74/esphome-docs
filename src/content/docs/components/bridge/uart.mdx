---
description: "Instructions for setting up a bridge between two UART buses in ESPHome"
title: "UART Bridge"
---

The `uart` platform of the [Bridge](/components/bridge/) component copies bytes unchanged, in both directions,
between two [UART](/components/uart/) buses. Each bus keeps its own baud rate, data bits, parity and stop bits.
Two serial devices that were wired to each other keep talking, with this device between them and one UART on
each device. To sniff those bytes, for example over TCP, put a UART split on one bus, connect this bridge to
one of its outputs, and publish a receive-only output with [UART TCP](/components/uart_tcp/).

```yaml
# Example configuration entry
uart:
  - id: device_a
    tx_pin: GPIO17
    rx_pin: GPIO16
    baud_rate: 9600
  - id: device_b
    tx_pin: GPIO4
    rx_pin: GPIO5
    baud_rate: 9600

bridge:
  - platform: uart
    uart_id: device_a
    peer_id: device_b
```

## Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID of this bridge.
- **uart_id** (**Required**, [ID](/guides/configuration-types#id)): One UART bus.
- **peer_id** (**Required**, [ID](/guides/configuration-types#id)): The other UART bus.
